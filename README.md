# İZLEK Bench

CMPE/EEEN 566 · Semi KIRCI

A benchmark of valid state updates and source attribution in Turkish dialogues.

- 60 test cases and 12 development cases.
- Three recorded model runs (180 API responses).
- Joint exact: GPT-OSS 120B 90%, Qwen 3.8 27B 88.33%, GPT-OSS 20B 46.67%.
- Academic English report, task-family analysis, strict-format caveats, and reproducible scores.

The complete source, dataset, preserved test responses, tests and report are in `izlek-project.zip`.
This repository serves the prebuilt static interface from the root of `main` using GitHub Pages.
AI assistance is disclosed in the report. Independent human annotation review is not claimed.

Open `index.html` through an HTTP server, not file://. No API key is needed to use the site.
